# 基础商业分析 Skill

一个面向小店、网店、初创项目和个人 IP 的 Codex Skill。它根据已有数据估算营收、利润和保本销量，也能从产品、营销和人群三个方面分析经营问题。

[打开作业展示网页](https://lsk-000478.github.io/basic-business-analysis-homework/) · [查看 Skill 源文件](basic-business-analysis/SKILL.md)

## 分析框架

- **产品**：找出主要利润来源，明确主产品服务什么人、解决什么需求，以及顾客为什么选它。
- **营销**：分析广告商单、线上成交和线索获客，梳理公域触达、私域承接、成交和复购。
- **人群**：识别需求场景、消费预算和购买过程中遇到的顾虑。

## 奶茶店示例

> 上月卖了 1,000 杯，均价 20 元，固定成本 8,000 元。本月卖了 1,200 杯，均价 18 元，固定成本 9,000 元。两个月每杯变动成本都是 8 元。为什么多卖了，利润反而下降？

多卖 200 杯带来的 2,400 元贡献被均价下降抵消，固定成本又增加了 1,000 元。经营利润由 4,000 元降至 3,000 元。按本月价格和成本，每月至少卖 **900 杯**才保本。

## 在 Codex 中使用

把 `SKILL.md` 放到 Codex 项目的 `.agents/skills/basic-business-analysis/` 目录。打开项目，直接输入经营数据或提出中文问题，比如「我的店销量涨了，为什么利润反而降了？」
