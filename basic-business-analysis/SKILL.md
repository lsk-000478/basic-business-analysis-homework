# 基础商业分析

从用户要做的决定出发，例如要不要继续做优惠，或先试卖还是直接开店。根据现有材料回答，并指出哪些数据会改变判断。

回答具体问题时，选用直接相关的部分。做整体经营诊断或验证新生意时，从产品、营销和人群三个方面分析，并结合现有数据判断经营结果。

## 已有经营数据

1. 对齐周期、币种、销量单位和收入口径。比较前后两期时，确认退款、折扣和成本项目的记录方式一致。若收入总额与销量乘均价不符，检查均价是否四舍五入或存在口径差异，并说明采用哪组数字及理由。
2. 按问题选算适用的指标。对单一产品或单位成本可合理用加权均值表示的业务，可用下列关系。已有可靠的汇总金额时，直接使用汇总金额。

   | 指标 | 算法 |
   | --- | --- |
   | 销售收入 | 销量 × 平均实际成交价 |
   | 变动成本 | 销量 × 平均单位变动成本 |
   | 单位贡献 | 平均实际成交价 − 平均单位变动成本 |
   | 经营利润估算 | 销售收入 − 变动成本 − 固定成本 |
   | 保本销量 | 固定成本 ÷ 单位贡献。销量以整件计时向上取整 |

   保本销量要求单位贡献为正，并假设测算范围内的售价、单位变动成本和固定成本保持稳定。单位贡献为零时，增加销量不会带来额外贡献。单位贡献为负时，增加销量会增加亏损。仅在比较基期大于零时报告相对增减百分比。基期为零或为负时，报告金额变化并指出扭亏或转亏情况（如有）。
3. 解释利润变动时分清销量、价格和成本。只有单一产品且两期数据齐全时，可按顺序量化：销量影响 = 销量变化 × 上期单位贡献，价格影响 = 平均成交价变化 × 本期销量，单位变动成本影响 = −单位变动成本变化 × 本期销量，固定成本影响 = −固定成本变化。各影响加总应与利润变化相符（舍入误差除外）。多品类且产品结构明显变化时，优先按品类比较，或说明汇总均价可能受产品结构影响。

## 产品、营销和人群

### 产品

- 梳理在卖的商品或服务，找出主要利润来源。有分项销售和成本数据时，用各产品的实际销售收入减去变动成本，比较贡献额。要比较单品经营利润，还需明确专属固定成本和共同成本的分摊口径。
- 说明主产品服务哪类人、他们在什么场景下遇到什么问题。对照他们现有的替代选择，找出独特的成交理由。如果判断某个优势是护城河，说明它为什么难以复制，并指出支持判断的证据。

### 营销

- 公域业务按实际情况识别主要变现或获客方式。常见方式有广告商单、线上成交、线索获客。线索获客可看有效线索数和后续成交率，实际收入以已确认的成交收入为准。
- 涉及个人 IP 时，判断业务属于哪些形态，包括自媒体、本地生活、电商、知识付费和解决方案。涉及多种形态时，说明各自怎么收费或获客。
- 按业务实际画出从公域触达、咨询或私域承接，到下单、成交和复购的链路。有数据时，注明各阶段的转化率口径，找出流失最大的环节。

### 人群

- **人群需求场景。** 明确谁在什么情况下需要解决什么问题。适用时，区分使用者和付款者，并说明目前怎么解决。
- **消费心理账户。** 判断顾客把这笔钱归到哪类预算，例如日常必需、犒劳自己或送礼。说明这种归类对预算、价格敏感度和选择的影响。
- **消费心理旅程。** 梳理顾客在需求触发、了解、比较、购买和复购各阶段的主要顾虑。用咨询、访谈、评论或订单等证据支持判断，待验证的推测标为假设。

## 只有生意点子或数据不足

- 对已有生意，先报告能确定的结果。缺少成本时先给已有收入和销量结论，指出缺哪些成本才能估算利润。对矛盾或关键缺失的数据，请用户补充最影响判断的项目。
- 对新生意，用产品、营销和人群三个方面梳理经营假设，同时列出收费方式和主要成本。标明用户给出的事实与待验证的假设。需要估算时列出假设，并展示售价、销量或成本中最影响决策的一项如何改变结果。

## 回答方式

先用一句话回答经营问题，再用简表或算式展示关键数据和依据，最后给出下一步行动。把已知数字、估算、可能原因和待验证项写清楚。缺少证据时，将客流、复购、竞争或优惠等原因表述为假设。

建议试行某个方案时，写清观察指标及据此作决定的条件。数据不足以定阈值时，说明还需要什么信息，或把试验阈值标为拟定值。
